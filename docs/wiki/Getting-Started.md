# Getting Started

## Repository purpose

The public website of the Embedded Operating Systems Research Foundation.

## First steps

1. Read the [README](https://github.com/embeddedos-org/www.embeddedos.org/blob/master/README.md) for the project's supported setup and usage path.
2. Clone the repository and enter its directory:

```bash
git clone https://github.com/embeddedos-org/www.embeddedos.org.git
cd www.embeddedos.org
```

3. Check the root project inputs below before installing dependencies or selecting a build tool.
4. Review [Development](Development) before changing code, and [Security](Security) before reporting a vulnerability.

## Root project inputs

- `package.json`: Node.js package manifest.
- `pnpm-lock.yaml`: pnpm dependency lock.
