Our Mission

Embedded computing should be free to learn and free to build on

The Embedded Operating Systems Research Foundation is a 501(c)(3) public charity (EIN 41-4821627). We exist to advance open-source embedded systems research, education, and technology for the public benefit — accountable to our community, not to shareholders. Every line of code we publish is MIT licensed and free, forever.

Open-source software, permanently free

The kernel, bootloader, drivers, build tools, and every application we ship are MIT licensed and developed in public on GitHub. No paid tiers, no license fees, no vendor lock-in.

Free education for engineers and students

14 full-length technical books, a 300+ API reference, free certification exams, a Kids Edition for classrooms, and paid internships for students and new graduates — all at no cost to learners.

Public-benefit research

We publish our research openly, including patent filings for health-monitoring hardware, so that clinicians, universities, and other nonprofits can build on the work rather than license it.

The Complete Embedded Ecosystem

Every component you need to build, deploy, and manage embedded systems at any scale.

Core

EOS Kernel

The core real-time operating system kernel with sub-microsecond latency and deterministic scheduling.

Security

eBoot

Secure, verified bootloader with hardware attestation, rollback protection, and OTA update support.

Platform

EIPC

High-performance inter-process communication with zero-copy message passing and typed channels.

AI

eAI Edge

On-device AI inference runtime supporting TensorFlow Lite, ONNX, and custom neural network models.

Security

eSec

Comprehensive security and cryptography layer with hardware security module integration.

Network

eNet

Full networking stack supporting TCP/IP, MQTT, CoAP, and custom embedded protocols.

Apps

eApps

60+ curated embedded applications covering productivity, monitoring, and system management.

Data

eDB

Lightweight embedded database with SQL support, optimized for flash storage and low RAM.

UI

eBrowser

Minimal web browser engine for embedded displays with CSS and JavaScript support.

Apps

eOffice

11 office applications including document editor, spreadsheet, and presentation tools.

Education

Kids Edition

Educational embedded OS platform with interactive learning modules and parental controls.

Dev Tools

eFlow

Visual programming environment for embedded systems with drag-and-drop logic blocks.

Why EmbeddedOS?

The Operating System for Every Device

Built by embedded engineers, for any embedded hardware. Every design decision prioritizes reliability, security, and developer experience.

01

Real-Time Performance

Sub-microsecond interrupt latency with deterministic scheduling for mission-critical applications.

02

Security First

Hardware-backed security, secure boot, and encrypted storage built into every layer.

03

Universal Connectivity

WiFi, Bluetooth, Ethernet, CAN bus, and custom protocol support out of the box.

04

Developer Friendly

300+ APIs, comprehensive docs, 14 technical books, and an active open-source community.

05

Modular Architecture

Use only what you need — from bare-metal kernel to full application stack.

06

Production Ready

Board definitions for 83 targets spanning automotive, industrial, and IoT hardware.
