All Projects

22 open-source repositories across 6 categories — all MIT licensed, all on GitHub.

⚙️ Core OS

EoS Kernel

MIT

Real-time microkernel for ARM Cortex-M and Linux. Tickless scheduler, MPU isolation, formal verification target.

github.com/embeddedos-org/EoS →

eBoot

MIT

Secure bootloader with Ed25519 signatures, A/B partitions, anti-rollback counters, and runtime attestation.

github.com/embeddedos-org/eBoot →

eIPC

MIT

Zero-copy inter-process communication with hardware MPU protection and deterministic bounded latency.

github.com/embeddedos-org/eIPC →

ebuild

MIT

CMake-based build system with declarative board descriptions. Generates linker scripts and BSPs automatically.

github.com/embeddedos-org/ebuild →

🤖 AI & Neural

eAI

MIT

Embedded AI inference engine. INT4/INT8/FP16 quantization, ARM Helium SIMD, on-device LLM runtime.

github.com/embeddedos-org/eAI →

eNI

MIT

Neural interface platform. 1024-channel BCI signal processing, real-time spike sorting on Cortex-M7.

github.com/embeddedos-org/eNI →

eosllm

MIT

On-device LLM runtime for EmbeddedOS. Quantized transformer inference optimized for constrained hardware.

github.com/embeddedos-org/eosllm →

🛠️ Dev Tools

EoSim

MIT

Hardware simulation engine with HIL bridge. Run EoS images on virtual boards or drive real silicon from simulation.

github.com/embeddedos-org/EoSim →

EoStudio

MIT

Integrated development environment for EmbeddedOS. Code editor, debugger, board flasher, and EoSim integration.

github.com/embeddedos-org/EoStudio →

📱 Applications

eOffice

MIT

Office productivity suite: word processor, spreadsheet, presentation, PDF viewer — all running on EmbeddedOS.

github.com/embeddedos-org/eOffice →

eBrowser

MIT

Embedded web browser with HTML5, CSS3, and JavaScript support optimized for constrained devices.

github.com/embeddedos-org/eBrowser →

eDB

MIT

Embedded database engine with AES-XTS at-rest encryption, ACID transactions, and 6 KB code footprint.

github.com/embeddedos-org/eDB →

eApps

MIT

60+ applications for EmbeddedOS across 6 categories: productivity, communication, media, utilities, dev tools, education.

github.com/embeddedos-org/eApps →
