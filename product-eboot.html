BOOT PLATFORM

eBootloader Staged Boot Platform

Secure, staged boot from power-on to verified OS handoff

Two-Stage Boot

Stage-0 (16KB): vector table, .data/.bss init, recovery check. Stage-1: full boot policy, image verification, slot selection.

A/B Slot Management

Dual firmware slots with independent boot control blocks. CRC32 integrity verification and optional cryptographic signatures.

Auto-Rollback

Automatic rollback after 3 consecutive boot failures. Dual-copy boot control blocks with redundancy for corruption protection.

Flash Memory Layout

1

Stage-0 (16KB min)

Vector table + .data/.bss init + recovery button check + jump to Stage-1

2

Stage-1 (64KB min)

Boot policy engine + CRC32/signature verify + A/B slot selection + OS handoff

3

Boot Control (4KB x2)

Primary + backup boot control blocks with active slot, boot count, CRC32 protection

4

Slot A + Slot B

Two firmware image slots for OTA-safe updates. Remaining flash divided equally.
