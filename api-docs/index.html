Hardware Abstraction Layer

Low-level hardware access — GPIO, UART, SPI, I²C, Timer, Interrupts

HAL Initialization

Initialize the HAL layer. Must be called before any peripheral API.

Returns

0 on success, negative error code.

Example
if (eos_hal_init() != 0) panic("HAL init failed");

Shut down all HAL peripherals and release resources.

Returns

void

Example
eos_hal_deinit(); // clean shutdown

Block the calling task for at least ms milliseconds.

Returns

void

Example
eos_delay_ms(1000); // 1 second delay

Return the number of milliseconds since HAL initialization.

Returns

Tick count in milliseconds.

Example
uint32_t t0 = eos_get_tick_ms();
// ... work ...
uint32_t elapsed = eos_get_tick_ms() - t0;

Kernel (RTOS)

Lifecycle

Start the RTOS scheduler. Never returns. All tasks must be created before this call.

Returns

Never returns.

Example

eos_kernel_start();

Return the current RTOS tick count (increments at configTICK_RATE_HZ).

Returns

Current tick count.

Example
uint32_t t = eos_kernel_get_tick();

Suspend the scheduler. All tasks freeze. Use for atomic multi-step operations.

Returns

void

Example
eos_kernel_suspend();
// atomic update
eos_kernel_resume();

Resume the scheduler after eos_kernel_suspend().

Returns

void

Example
eos_kernel_resume();

FieldTypeDescription

Returns

Returns

void

Example

Returns

void

Example

Resume a previously suspended task.

Returns

void

Example

Yield CPU to any equal or higher priority task.

Returns

void

Example

Block the calling task for a number of RTOS ticks.

Returns

Message Queue

Create a message queue with fixed item size and depth.

Returns

0 on success, EOS_ERR_NOMEM if allocation fails.

Example

Copy item into queue. Blocks if queue is full.

Returns

0 on success, EOS_ERR_TIMEOUT if timed out.

Example

Remove and copy item from queue. Blocks if queue is empty.

Returns

0 on success, EOS_ERR_TIMEOUT if timed out.

Example

if (eos_queue_recv(&sensor_q, &r, 100) == 0) process(&r);

Copy front item without removing it from the queue.

Returns

0 on success, EOS_ERR_TIMEOUT if timed out.

Example

Return number of items currently in the queue.

Returns

Item count.

Example

Remove all items from the queue.

Returns

void

Example

Delete queue and free memory.

Returns

void

Example

Returns

0 on success, EOS_ERR_BUSY if update already in progress.
