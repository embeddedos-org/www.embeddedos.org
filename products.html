EoS RTOS · Tier 1 · Kernel

EoS RTOS

The world's most capable open-source embedded RTOS.

EoS is a real-time operating system designed from the ground up for the demands of modern embedded AI applications. It delivers deterministic scheduling, formally verified context switching, and a tickless idle mode with sub-microsecond wake latency. EoS runs on ARM Cortex-M, Cortex-A, and RISC-V targets and is the kernel that powers every other component in the EmbeddedOS stack.

  • Tickless scheduler with sub-microsecond wake latency
  • Formally verified context-switch path (2026 roadmap)
  • RT-IPC primitives for cross-security-domain memory sharing
  • ARM Cortex-M0 through M85, Cortex-A, and RISC-V support
  • POSIX-compatible threading and synchronization primitives
  • Integrated power management with dynamic voltage/frequency scaling

eBootloader · Tier 1 · Boot

eBootloader

Secure, chain-of-trust boot for every ARM target.

eBootloader implements a complete hardware-rooted chain of trust for ARM Cortex-M devices. It supports A/B partition OTA updates, cryptographic rollback protection, and integrates with hardware security modules (HSM) and TrustZone. It is the first instruction your device executes — and the most important one.

  • Hardware root-of-trust with TrustZone and HSM integration
  • A/B partition OTA with atomic swap and rollback
  • Ed25519 firmware signature verification
  • Anti-rollback counter in OTP/eFuse
  • Supports UART, USB DFU, and BLE OTA transports

eBuild · Tier 1 · Build System

eBuild

One command. Any component. Any architecture.

eBuild is the unified build system and cross-compiler toolchain manager for the entire EmbeddedOS stack. It wraps CMake and Ninja with EoS-specific configuration, manages ARM GCC, LLVM, and RISC-V toolchain downloads, and provides reproducible builds across all 14 components. One command builds everything.

  • Manages ARM GCC, LLVM/Clang, and RISC-V GCC toolchains
  • Reproducible builds via pinned toolchain versions and Nix-style hashing
  • CMake + Ninja backend with EoS board support package (BSP) system
  • Docker-based CI builds for all 7+ target architectures
  • Integrated with eos-stack-manifest for unified multi-repo builds

EAI · Tier 2 · Embedded AI Runtime

EAI — Embedded AI

The world's most efficient on-device LLM runtime for microcontrollers.

EAI delivers INT4-quantized large language model inference at 11 tokens per second on a 480 MHz ARM Cortex-M85 — with no cloud dependency, no network latency, and no data leaving the device. It supports ONNX, TFLite, and custom EoS model formats, and integrates directly with the EoS RTOS scheduler for deterministic inference windows.

  • 11 tok/s INT4 LLM inference on 480 MHz Cortex-M85
  • 1.3B-parameter model in 312 MB flash (INT4 quantized)
  • ONNX, TFLite Micro, and EoS native model formats
  • CMSIS-NN and RISC-V Vector Extension acceleration
  • Deterministic inference windows via EoS RTOS scheduler integration
  • Python SDK for model quantization, conversion, and profiling

ENI · Tier 2 · Neural Interface

ENI — Embedded Neural Interface

The world's only open-source neural interface RTOS stack.

ENI processes 1,024 simultaneous neural channels through a complete signal pipeline — bandpass filtering, spike detection, sorting, and decoding — in a single 800 microsecond RTOS frame. It runs on Nordic nRF52840 and ARM Cortex-M4, and is designed for medical-grade neural recording and brain-computer interface applications.

  • 1,024-channel simultaneous neural signal processing
  • 800 µs end-to-end latency (filter → sort → decode)
  • Runs on nRF52840 and ARM Cortex-M4 at 64 MHz
  • Adaptive spike sorting with online template matching
  • BLE streaming of decoded neural events to host
  • IEC 62304 medical device software compliance pathway

EIPC · Tier 2 · IPC Daemon

EIPC

High-performance device-to-host communication. Cross-platform.

EIPC is a Go-based inter-process communication daemon that bridges EoS device data to host applications over USB, BLE, and Wi-Fi. It runs on Linux, macOS, and Windows, exposes a gRPC API for host applications, and handles connection management, protocol framing, and data buffering transparently.

  • Go-based daemon — single binary, zero dependencies
  • USB CDC, BLE GATT, and Wi-Fi TCP transport support
  • gRPC API for host application integration
  • Runs on Linux, macOS, and Windows natively
  • Auto-discovery of EoS devices via USB VID/PID and BLE advertisement

EoStudio · Tier 3 · IDE

EoStudio

The IDE that knows your RTOS.

EoStudio is a full-featured embedded IDE built on the VS Code engine, extended with deep EoS RTOS awareness. It provides AI-assisted code completion trained on EoS APIs, an integrated J-Link/OpenOCD debugger with RTOS-aware thread and stack visualization, one-click flash for all EoS targets, and a built-in EAI model profiler.

  • VS Code engine with EoS-specific extensions pre-installed
  • AI code completion trained on EoS APIs and patterns
  • RTOS-aware debugger: thread list, stack usage, mutex visualization
  • Integrated J-Link, OpenOCD, and CMSIS-DAP support
  • EAI model profiler: latency, memory, and accuracy analysis
  • Available as desktop app (Linux, macOS, Windows) and VS Code extension

EoSim · Tier 3 · Simulator

EoSim

Run your firmware before you have hardware.

EoSim is a hardware-in-the-loop simulator and full-system emulator for EoS firmware. It provides QEMU-backed emulation of Cortex-M and Cortex-A targets, a custom SoC model API for peripheral simulation, and a Python scripting interface for automated test scenarios. Run complete EoS firmware — including EAI inference — on your laptop.

  • QEMU-backed Cortex-M and Cortex-A emulation
  • Custom SoC model API for GPIO, UART, SPI, I2C, ADC simulation
  • EAI inference simulation with cycle-accurate timing
  • Python scripting for automated HIL test scenarios
  • GDB remote stub for source-level debugging in EoStudio
  • CI integration via Docker image

eOffice · Tier 4 · Productivity Suite

eOffice

AI-powered productivity. Works offline. Everywhere.

eOffice is an AI-powered productivity suite that integrates with every environment an embedded developer works in. It ships as a Chrome/Firefox browser extension, a VS Code plugin, a Google Workspace add-on, a JetBrains plugin, and an Obsidian plugin. All features work offline using the local EAI runtime — no data leaves your machine.

  • Chrome and Firefox browser extension
  • VS Code and JetBrains IDE plugins
  • Google Workspace (Docs, Sheets, Gmail) add-on
  • Microsoft Office 365 add-in
  • Obsidian plugin for knowledge management
  • Offline AI via local EAI runtime — zero cloud dependency

eDB · Tier 4 · Database

eDB

Encrypted, time-series database for embedded and edge.

eDB is an embedded-first database designed for sensor telemetry, neural recording data, and device event logs. It provides AES-256 encryption at rest, a time-series storage engine optimized for high-frequency sensor data, and a web UI for data exploration. It runs on device, as a desktop app, or as a cloud-hosted service.

  • AES-256 encryption at rest with hardware key storage
  • Time-series storage engine: 10,000+ writes/second on embedded targets
  • Web UI for data exploration and visualization
  • SQL-compatible query interface
  • Desktop app (Linux, macOS, Windows) and on-device library
  • Replication to cloud via EIPC bridge

eBrowser · Tier 4 · Browser

eBrowser

The browser built for embedded developers.

eBrowser is a privacy-first browser with built-in BLE device management, an EoS device dashboard, and a Chrome/Firefox extension for embedded developers. It provides a unified interface for monitoring connected EoS devices, streaming live sensor data, and managing firmware OTA updates — all from the browser.

  • Built-in BLE device scanner and connection manager
  • Live EoS device dashboard with sensor data visualization

  • Privacy-first: no telemetry, no tracking, local-only data

Tier 5 — Platform & Distribution

The unified meta-distribution for the entire stack.

eos-platform · Tier 5 · Meta-Distribution

eos-platform

One toolchain. Every EoS profile. Reproducible everywhere.

eos-platform is the meta-distribution that ties all 14 EoS components together into a single, versioned, reproducible build. It provides stable APIs, a unified package manifest, and profile-based builds (minimal, standard, full-AI, neural) that select the right subset of components for your target device. eos-platform 1.0 is the first stable release.

  • Stable, versioned API surface across all 14 components
  • Profile-based builds: minimal (8 KB), standard, full-AI, neural
  • Unified package manifest with pinned component versions
  • Reproducible builds via eBuild + Docker
  • eApps registry integration for third-party component discovery
