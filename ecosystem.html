Known Barriers

What is blocking each platform — and how we resolve it.

We are transparent about what is not yet available and exactly what is needed to ship it. Every barrier has a resolution path.

📱 iOS / Apple Platform
  • Apple Developer Account — $99/year enrollment required for all iOS distribution. Resolution: Foundation membership funds enrollment.
  • EAS Project ID — Expo Application Services project must be registered per app. Resolution: CI automation via EAS CLI.
  • BLE Core Bluetooth entitlement — NSBluetoothAlwaysUsageDescription + entitlement required. Resolution: Info.plist update + provisioning profile.
  • WebKit-only browser engine — Apple mandates WebKit for all iOS browsers. eBrowser cannot use its own engine on iOS. Resolution: WebKit-wrapped build.
  • macOS notarization — All macOS binaries must be notarized via Apple's notary service. Resolution: CI notarization step with Apple ID credentials.
🤖 Android / Google Play
  • Play Store policy for browsers — Google Play restricts alternative browser engines. eBrowser requires side-loading or F-Droid distribution. Resolution: F-Droid listing + direct APK.
  • BLE permissions (Android 12+) — BLUETOOTH_SCAN, BLUETOOTH_CONNECT, and BLUETOOTH_ADVERTISE permissions required. Resolution: Runtime permission request flow.
  • Play signing key — Google Play App Signing requires upload key + Play signing key pair. Resolution: Foundation-managed keystore in CI secrets.
  • Capacitor sync — eOffice web assets must be synced to Android project via npx cap sync. Resolution: CI step added to web build job.
🌐 Browser Extensions
  • Chrome Web Store review — 2–7 day review cycle for new extensions. Resolution: Submit EoStudio extension; review in progress.
  • Firefox MV3 gaps — Firefox's Manifest V3 implementation is incomplete vs Chrome. Some EoStudio extension APIs unavailable. Resolution: MV2 fallback build for Firefox.
  • vsce packaging — VS Code extensions require vsce CLI + publisher account. Resolution: Foundation publisher account; CI step added.
  • Office 365 Add-in signing — Microsoft requires a code-signing certificate for Office Add-ins. Resolution: EV certificate procurement via Foundation budget.
  • JetBrains Marketplace — Plugin must pass JetBrains compatibility verification. Resolution: Plugin SDK integration in progress.
🖥️ Desktop (Windows / macOS)
  • Windows code signing — EV certificate required to avoid SmartScreen warnings. Resolution: DigiCert EV certificate via Foundation budget.
  • Apple notarization CI — Requires Apple ID + app-specific password in CI secrets. Resolution: Foundation Apple ID configured; notarization step pending.
  • Electron packaging — electron-builder configuration for each app required. Resolution: Shared electron-builder config template added to eFab.
  • PyInstaller cross-compile — eVera PyInstaller builds must run on target OS (no cross-compile). Resolution: GitHub-hosted Windows/macOS runners in CI.
  • MSVC toolchain — Some C extensions in eVera require MSVC on Windows. Resolution: windows-latest runner with MSVC pre-installed.
