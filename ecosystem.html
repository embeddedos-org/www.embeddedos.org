Overview

The Complete Stack

Seven open-source projects forming a unified embedded AI platform

The EoS ecosystem brings together seven purpose-built projects that span the entire embedded systems lifecycle. From the eBootloader that initializes hardware, through the EoS build system that compiles your OS image, to the EAI runtime that powers edge AI, the EIPC framework securing inter-process communication, and the ENI adapter bridging neural interfaces — every layer is designed to work together as a cohesive, open-source stack.

Ecosystem Projects

Explore each component of the EoS stack

🏗️ eBuild — Build System & AI Hardware Analyzer

Python-based build orchestrator with built-in AI hardware analyzer (100+ MCU database, KiCad/Eagle parsers), package manager with topological dependency resolution, system image builder (ext4, squashfs, qcow2), and firmware builder (Zephyr, FreeRTOS, NuttX). Auto-detects CMake, Meson, Cargo, Make, Ninja, and Kbuild projects.

Python 3.9+ v0.4.0 AI Analyzer Package Mgr 6 Build Backends
View on GitHub →

⚙️ EoS — Embedded Operating System

Modular C11 firmware framework with 6-layer architecture: HAL (vtable dispatch for 25 boards), kernel (scheduler, memory, IPC), device drivers, services, middleware, and applications. 39 compile-time feature flags (EOS_ENABLE_*), 41 product profiles, CMake build with cross-compilation for ARM Cortex-M/A, x86, RISC-V.

C11 v0.5.0 CMake 25 Boards 41 Products
View on GitHub →

⚡ eBootloader — Staged Boot Platform

Two-stage C11 bootloader: Stage-0 (16KB — vector table, .data/.bss init, recovery check) and Stage-1 (boot policy, CRC32/signature verification, A/B slot management). Dual-copy boot control blocks with redundancy, automatic rollback on 3 consecutive failures, and OTA-safe firmware upgrades across 24 platform targets.

C11 v0.3.0 CMake A/B Slots 24 Platforms
View on GitHub →

🤖 EAI — Embedded AI Runtime

Zero-dependency C11 AI agent runtime. EAI-Min: lightweight edge agent with tool registry (64 tools), memory store (1024 entries), and local LLM inference. EAI-Framework: industrial orchestration with 8 runtime slots, 16 connectors (MQTT, OPC-UA, Modbus, CAN), policy engine, and observability. Receives intents from ENI via EIPC bridge.

C11 v0.1.0 Zero Deps MQTT/OPC-UA 64 Tools
View on GitHub →

🧠 ENI — Embedded Neural Interface

Zero-dependency C11 neural interface adapter. ENI-Min: single-provider BCI with signal normalization, confidence filtering (threshold + debounce), intent-to-tool mapping, and 3-tier safety policy (safe/controlled/restricted). ENI-Framework: multi-provider (16 slots), 256-entry stream bus, cognitive pipeline with FFT/bandpass/spatial filters. Forwards intents to EAI via EIPC bridge.

C11 v0.1.0 Zero Deps BCI/Neural 16 Providers
View on GitHub →

🔒 EIPC — Embedded Secure IPC

Go 1.22 + C11 SDK secure inter-process communication. Wire protocol: 16-byte preamble + JSON header + JSON payload + HMAC-SHA256 (built-in SHA-256, zero deps). Features: capability-based authorization, service registry, audit logging, health monitoring, replay protection (128-entry sliding window), priority lanes P0–P3. C SDK enables ENI↔EAI communication.

Go + C SDK v0.1.0 HMAC-SHA256 Cap-Auth Zero Deps
View on GitHub →
Quick Start

Getting Started

Build your first embedded OS image in four steps

  1. Clone EoS

    Get the core build system repository:

    git clone https://github.com/embeddedos-org/eos

  2. Configure Your Target

    Define your board, architecture, and feature set in a YAML configuration file.

  3. Compile

    Run the build system to cross-compile for your target platform:

    eos build

  4. Generate OS Image

    Create a deployable OS image ready for flashing:

    eos system
