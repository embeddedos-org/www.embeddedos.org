All Products

Every Product, Explained

🔮
EoS
Core RTOS Kernel

Real-time kernel with capability-based security, SMP/AMP support, deterministic scheduling, and a hardware abstraction layer for 50+ MCU families.

≤10μs context switch ARM · RISC-V · x86 C11 standard
🔐
eBootloader
Secure Boot Chain

5-stage verified boot with hardware root of trust, rollback protection, A/B partition updates, and cryptographic signature verification.

Ed25519 signatures A/B updates <64KB footprint
🧠
EAI
AI Inference Engine

On-device neural inference at sub-1ms latency. Runs quantised LLMs, CNNs, and transformers on microcontrollers with as little as 256KB RAM.

<1ms inference INT8/INT4 quant 256KB min RAM
🧬
ENI
Neural Interface

1,024-channel neural signal acquisition at 30kHz with 24-bit ADC, real-time spike sorting, and low-latency BCI output for brain-computer interfaces.

1,024 channels 30kHz sample rate 24-bit ADC
⚡
EIPC
IPC Bus

Zero-copy inter-process communication with capability tokens, message queues, shared memory, and sub-microsecond latency between isolated processes.

<1μs latency Zero-copy Capability tokens
🔧
eBuild
Build System

Declarative cross-compilation build system with reproducible builds, SDK generation, and support for 20+ toolchains including GCC, Clang, and LLVM.

Reproducible builds 20+ toolchains SDK generation
🖥
EoSim
System Simulator

QEMU-based full-system simulator with virtual peripherals, GDB integration, hardware-in-the-loop bridge, and cycle-accurate timing for deterministic testing.

QEMU backend HIL bridge GDB integration
💻
EoStudio
IDE

RTOS-aware IDE with live task inspector, memory map visualiser, one-click flash, integrated EoSim, and real-time CPU/memory profiling dashboards.

RTOS task view Memory map One-click flash
🗄
eDB
Embedded Database

Full SQL embedded database with AES-XTS encryption at rest, write-ahead logging for crash safety, B-tree indexing, and a 64KB minimum footprint.

AES-XTS encryption WAL crash safety 64KB footprint
🏗
EoS Platform
Platform SDK

Unified platform SDK that integrates all EoS products into a single development environment with shared APIs, documentation, and tooling.

Unified API All products One SDK
📱
eApps
App Framework

Lightweight application framework for building embedded UIs and services on EoS, with a component model, event system, and hardware-accelerated rendering.

Component model HW-accelerated Event system
🌐
eBowser
Embedded Browser

Lightweight web browser for embedded devices with HTML5, CSS3, and JavaScript support. Runs on devices with as little as 4MB RAM.

HTML5 / CSS3 4MB min RAM JavaScript
📄
eOffice
Office Suite

Embedded office suite with document viewer, spreadsheet engine, and presentation renderer. Compatible with standard office formats.

DOCX / XLSX PDF renderer Offline first
⚙️
eServiceApps
System Services

Collection of system service applications: network manager, update daemon, logging service, health monitor, and remote management agent.

OTA updates Health monitor Remote mgmt
