EoS Build System Engineer Engineering Senior

Design and maintain the EoS build system, Ninja backend integration, YAML configuration, and cross-compilation targets for ARM, x86, and RISC-V architectures.

💼 Full-time📍 Remote / San Francisco Bay Area👥 Core Platform
▼

Responsibilities

  • Design and maintain the ebuild build system with Ninja backend integration
  • Develop YAML-based board configuration and cross-compilation toolchains
  • Implement and optimize build pipelines for ARM Cortex-M/A, x86, and RISC-V targets
  • Maintain CI/CD pipelines and automated testing infrastructure
  • Collaborate with firmware engineers on BSP integration
  • Write and maintain build system documentation

Requirements

  • 5+ years with embedded build systems (CMake, Make, Ninja, Meson)
  • Deep knowledge of cross-compilation toolchains for ARM and RISC-V
  • Experience with YAML/TOML configuration systems
  • Strong C/C++ and Python skills
  • Familiarity with CI/CD systems (GitHub Actions, Jenkins)
  • Experience with ELF binary formats and linker scripts

EIPC Security Engineer Engineering Senior

Develop and maintain the EIPC secure IPC framework including capability-based authorization, audit logging, replay protection, and transport security.

💼 Full-time📍 Remote / San Francisco Bay Area👥 Security & IPC
▼

Responsibilities

  • Design and implement capability-based authorization model for EIPC
  • Develop HMAC-SHA256 message authentication and replay protection
  • Implement audit logging and security event monitoring
  • Design transport security for shared memory, UART, SPI, and I²C backends
  • Conduct threat modeling and security reviews
  • Write security documentation and threat model reports

Requirements

  • 5+ years in embedded security or systems security
  • Deep knowledge of cryptographic primitives (HMAC, AES, ECC)
  • Experience with capability-based security models
  • Strong C skills and memory safety understanding
  • Experience with secure boot, TrustZone, or TEE technologies
  • Familiarity with IPC mechanisms

eBootloader / Firmware Engineer Engineering Senior

Design staged boot architecture, A/B slot management, CRC/signature verification, and firmware upgrade APIs for the eBoot bootloader running on 52+ embedded platforms.

💼 Full-time📍 Remote / San Francisco Bay Area👥 Boot & Firmware
▼

Responsibilities

  • Design staged boot architecture (ROM → eBoot → EoS)
  • Develop A/B slot management and rollback protection
  • Implement CRC verification, RSA/ECDSA signature validation
  • Build OTA firmware upgrade APIs and delta update support
  • Port eBoot to new MCU families (STM32, ESP32, NXP, Nordic, RP2040)
  • Write HAL drivers for flash, UART, SPI, and I²C boot interfaces

Requirements

  • 5+ years of embedded firmware development
  • Deep knowledge of ARM Cortex-M boot sequences
  • Experience with flash memory management and NOR/NAND flash
  • Strong C skills with bare-metal firmware experience
  • Knowledge of secure boot and code signing
  • Experience with JTAG/SWD debugging and hardware bring-up
