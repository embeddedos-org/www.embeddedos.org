eApps Cross-Platform Applications

43 embedded applications with LVGL touchscreen UI — built once, deployed everywhere across 7 toolchains.

Core Features

📱

43 Applications

A complete suite of embedded apps — Snake, eCalc, eSSH, eBot, eGuard, eMail, eMedia, and many more — ready to run on any supported platform.

🌐

Cross-Platform

7 toolchains supported: Linux, macOS, Windows, Android, iOS, TV, and Embedded targets. Write once, compile everywhere.

LVGL v9.1 UI

Hardware-accelerated touchscreen GUI powered by LVGL v9.1 with theme support, animations, and responsive layouts.
