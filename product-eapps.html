Headline Products

Flagship applications in the EoS ecosystem

📄 eOffice

11-app office suite: eDocs, eSheets, eSlides, ePlanner, eNotes, eMail, eDrive, eConnect, eDB, eForms, eSway. Available as Electron desktop, web, and 11 platform extensions.

🎨 EoStudio

Visual design IDE with 12 editors: 3D modeling, CAD, image editing, game development, UI design, UML diagrams, simulation, database, hardware layout, and code generation with LLM integration.

💻 EoSim

Hardware and platform simulator supporting 52+ boards across 12 architectures. QEMU integration, GUI renderers, cluster simulation. Available as desktop app and Docker container.

🌐 eBrowser

Privacy-first embedded web browser with custom C/SDL2 rendering engine. Runs on Windows, macOS, Linux, EoS native, and as WASM in other browsers.

📱 eServiceApps

5 full-featured Flutter mobile apps: eRide (ridesharing), eSocial (social network), eTrack (package tracking), eTravel (booking), eWallet (digital payments). Android + iOS.

🗃 eDB

Multi-model database engine supporting SQL, Document, and Key-Value stores. REST API, JWT authentication, AES-256 encryption, and eBot AI-powered natural language queries.
