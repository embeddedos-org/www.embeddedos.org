eBowser Embedded Web Browser

Lightweight HTML5/CSS rendering engine for resource-constrained devices

View on GitHub Explore Features

Core Features

🌐

HTML5/CSS Engine

Full DOM parsing, cascading stylesheets, box model layout, and flexbox support. Standards-compliant rendering in a compact footprint.

💻

Multi-Platform

SDL2 desktop target for development, native EoS embedded target for production, and WebAssembly target for browser-based deployment.

🔌

Embeddable API

Simple 4-function API: create, navigate, run, and destroy. Embed a full browser engine in any application with minimal integration effort.
