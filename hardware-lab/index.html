    158 repository platform profiles for firmware simulation without physical hardware.

  • Secure Boot

    Design goal: hardware-backed secure boot with eBoot; per-platform validation is pending.

  • Universal Drivers

    Unified driver-model goal; portability and hardware validation vary by target.

  • ebuild Targeting

    Repository tooling exposes target-based builds, for example: `ebuild build --target stm32h7`; results vary by target.

  • OTA Updates

    Design target: delta OTA updates with rollback protection; per-platform validation is pending.
