CORE OS

EoS Embedded Operating System

Modular C11 firmware framework — from HAL to application layer

25 Board Targets

Vtable-dispatch HAL with board definitions for STM32, nRF52, ESP32, i.MX, RPi, RISC-V, and more.

6-Layer Architecture

HAL → Kernel → Drivers → Services → Middleware → Applications. Each layer independently testable.

39 Feature Flags

Compile-time EOS_ENABLE_* guards. Only enabled modules are compiled — minimal binary size.

EoS Firmware Architecture

6

Application Layer

User applications, system utilities, configuration tools, monitoring dashboards

5

Middleware Layer

Communication protocols, file systems, network stack, encryption

4

Services Layer

Logging, config manager, watchdog, power management, OTA update service

3

Device Drivers

Auto-generated from CAD schematics: I2C, SPI, UART, GPIO, ADC, PWM, DMA

2

Kernel

Scheduler (preemptive/cooperative), memory manager, IPC primitives, interrupt dispatch

1

HAL (Hardware Abstraction)

Vtable dispatch (eos_hal_backend_t) for 25 boards. Platform-specific code isolated behind clean interfaces.
