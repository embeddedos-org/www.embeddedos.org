eBuild — Build System & SDK Generator

eBuild is the EoS build system and SDK generator — an 18-command CLI that drives configuration, cross-compilation, signing, packaging, and SDK generation for all 14 EoS components across every supported target.

Overview

What eBuild is

eBuild treats firmware as a composition: pick a board, pick a profile, pick a feature set, and eBuild resolves the dependency graph, fetches sources at pinned revisions, cross-compiles, signs, and produces a flashable artifact plus a matching SDK for downstream apps.

Builds are reproducible by default: same inputs, byte-identical outputs. CI integration is first-class — the same `ebuild` commands run locally and in pipelines.

Features

The shape of eBuild at a glance.

▣

18-Command CLI

init, configure, build, sign, package, sdk, test, fuzz, deploy, bench, debug, …

▣

14 SDK Targets

Auto-generates a build SDK for every component (EoS, EAI, ENI, EIPC, eBoot, eApps, …).

▣

Profile Composition

Combine board + product profile + feature flags; resolves the full dependency graph.

▣

Reproducible Builds

Pinned source revs, isolated toolchains, hash-stable outputs.

▣

Cross-Compile Matrix

ARM, AArch64, RISC-V, x86_64 toolchains managed automatically.

▣

Signing & Packaging

Built-in Ed25519 signing, .eos / .img / .hex / .uf2 packaging.

▣

CI-First

GitHub Actions, GitLab CI, Jenkins recipes shipped; same commands locally and in CI.

▣

Bench & Fuzz

Integrated micro-benchmark and fuzzer drivers for kernel / app modules.

▣

Workspace Mode

Multi-repo monorepos with shared toolchain caches.

Architecture

eBuild Build System Pipeline

The six-stage build pipeline from source code through eBuild configuration, CMake generation, Ninja compilation, link and packaging, to SDK/binary output, with 41 target profiles across 6 hardware categories.

Quick Start

Building Your First EoS Project

ShellQuick Start
# 1. Create a new project from template
ebuild new my_sensor_node --profile cortex-m4-stm32f4

# 2. Navigate to project directory
cd my_sensor_node

# 3. Configure the build (generates CMake files)
ebuild configure --release

# 4. Build the project
ebuild build

# 5. Run static analysis
ebuild lint --misra

# 6. Flash to target hardware
ebuild flash --port /dev/ttyUSB0

# 7. Generate SDK for distribution
ebuild sdk --output dist/my_sensor_node_sdk_v1.0.0.tar.gz

# 8. Run unit tests (host-side)
ebuild test --host

eBuild auto-detects the connected debug probe (J-Link, ST-Link, CMSIS-DAP).

Applications

Where eBuild Is Used

🏭

Production Firmware Builds

Reproducible, hermetic firmware builds with pinned toolchain versions and cryptographic build manifests for supply-chain security.

🔄

CI/CD Pipelines

Native GitHub Actions integration enables automated build, test, and sign workflows triggered on every pull request.

📦

SDK Distribution

Automatic SDK generation packages headers, pre-built libraries, and CMake config files for third-party integrators.

🧪

Multi-Target Testing

Build and test the same codebase against all 41 target profiles in parallel to catch hardware-specific regressions early.

🔒

MISRA Compliance

Integrated MISRA-C 2012 checker with suppression management for automotive and medical device certification workflows.

🌐

Multi-Platform Support

Build Windows, Linux, and macOS host tools alongside embedded firmware from a single eBuild workspace.
