EoStudio — Embedded IDE

EoStudio is the integrated development environment for EoS — twelve domain-specific editors, thirty-plus code generators, profile-aware build configuration, and one-click EoSim debugging in a single workspace.

Overview

What EoStudio is

Where a generic IDE forces you to learn the EoS toolchain through trial and error, EoStudio surfaces the entire stack: a board picker, a profile composer, a HAL configurator, a device-tree visualizer, an EIPC topology editor, an EAI prompt designer, and more — each one a first-class editor with code-gen wired in.

Hit Run and EoStudio drives eBuild to produce an artifact, hands it to EoSim, and drops you into a kernel-aware debugger with eIPC traffic visualized live.

Quick Start

Setting Up EoStudio

ShellQuick Start
# 1. Install VS Code (if not already installed)
#    https://code.visualstudio.com/

# 2. Install the EoStudio extension
code --install-extension embeddedos.eostudio

# 3. Open your EoS project
code /path/to/my_eos_project

# 4. Configure the debug probe in .vscode/launch.json
# EoStudio auto-generates this when you run "EoStudio: Initialize Project"

# 5. Build and flash from the Command Palette
#    Ctrl+Shift+P → "EoStudio: Build and Flash"

# 6. Start RTOS-aware debug session
#    Press F5 — EoStudio attaches GDB and shows the task list

# 7. Launch EoSim for hardware-free debugging
#    Ctrl+Shift+P → "EoStudio: Launch in Simulator"

EoStudio requires the eBuild CLI to be on your PATH.

Applications

Where EoStudio Is Used

💻

Firmware Development

Full-featured IDE experience for EoS firmware development with IntelliSense, refactoring, and integrated version control.

🐛

RTOS Debugging

RTOS-aware debugging shows all task states, stack usage, and blocked resources — not just raw register values.

⚡

Power Optimization

Energy trace visualization helps identify power-hungry code paths and optimize sleep/wake cycles for battery-powered devices.

🧪

Test-Driven Development

Integrated test runner for EoS unit tests with coverage visualization directly in the editor margin.

🤖

AI-Assisted Coding

Context-aware AI completions understand EoS APIs, suggest HAL driver patterns, and generate EIPC message schemas.

🎓

Education

University courses use EoStudio's visual task debugger to teach RTOS concepts with immediate, visual feedback.
