AI RUNTIME

EAI Embedded AI Runtime

Zero-dependency C11 AI agent runtime — from edge inference to industrial orchestration

EAI-Min — Edge Agent

Lightweight agent loop: Think (LLM inference) → Tool call parsing → Tool execution. 64-tool registry, 1024-entry memory store, local inference. Perfect for edge devices and resource-constrained environments.

EAI-Framework — Industrial

Full orchestration: 8 runtime slots, 16 connectors (MQTT, OPC-UA, Modbus, CAN), policy engine with allow/deny rules, observability with metrics export. Built for factory automation, PLC integration, and multi-agent systems.

EAI Agent Loop

1

Receive Intent (from ENI via EIPC)

eai_eipc_listener_receive_intent() → parse intent from EIPC frame → convert to agent goal

2

Think (LLM Inference)

Local inference engine processes goal + context + memory → generates tool call plan

3

Execute Tools

Tool dispatch: mqtt.publish, device.read, http.request, file.write — up to 64 registered tools

4

Respond

Send acknowledgment back via EIPC → update memory store → emit observability metrics
