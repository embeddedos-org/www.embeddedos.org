NEURAL INTERFACE

ENI Embedded Neural Interface

Vendor-neutral brain-computer interface adapter — from neural signal to safe tool call

ENI-Min — Lightweight BCI

Single-provider neural interface: signal normalization, confidence filtering with threshold + debounce, intent-to-tool mapping, and 3-tier safety policy (safe/controlled/restricted). Minimal footprint for edge devices.

ENI-Framework — Multi-Provider

Multi-provider system with 16 slots, 256-entry stream bus, cognitive pipeline (FFT, bandpass, spatial filters), advanced signal fusion, and full EIPC bridge integration for industrial BCI applications.

ENI Signal Processing Pipeline

1

Provider Poll

BCI device SDK provides raw neural signal data (EEG, EMG, or synthetic) via provider plugin

2

Signal Normalization

Raw data → structured event with type (intent/features/raw), confidence score, timestamp

3

Confidence Filter

Threshold check + debounce (min interval between same intents) → reject low-confidence signals

4

Intent Mapping & Safety

Map intent name → tool name. Check 3-tier safety policy: safe (auto-execute), controlled (requires EIPC auth), restricted (deny)

5

EIPC Bridge

eni_eipc_bridge_send_intent() → EIPC frame with HMAC-SHA256 → forwarded to EAI for execution
